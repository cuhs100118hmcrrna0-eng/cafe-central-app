# Café Central - Aplicación Web

## Descripción
Aplicación web que permite a los clientes de la cafetería "Café Central" consultar el menú y realizar pedidos desde un dispositivo móvil o computadora.

## Problema que resuelve
Evita filas y tiempos de espera en el mostrador, permitiendo a los clientes registrarse, ver precios actualizados y consultar el estado de su pedido en línea.

## Funcionalidades principales
- Consulta del menú.
- Visualización de precios.
- Registro de clientes.
- Selección de productos.
- Creación de pedidos.
- Consulta del estado del pedido.
